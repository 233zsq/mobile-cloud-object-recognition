# 实验与证据

负责人：模型训练负责人；独立评估由组长执行。

- `experiment-log.template.csv`：仅列名的记录模板，每次实验保存唯一 ID、PC、代码与数据版本、种子、参数、验证指标和耗时。
- `logs/`：本地训练日志与 TensorBoard 等原始输出，默认不进入 Git。
- `checkpoints/`：本地检查点、优化器状态，默认不进入 Git，并另行备份。
- `reports/`：经过整理的小型实验对照表、曲线、独立评估、混淆矩阵与性能结论，可进入 Git。

同一阶段候选使用一致的数据划分与评价口径。验证集用于选参，测试集用于冻结后的最终独立评估；实验日志中的 `validation_*` 字段不能填入测试集指标。

四台 PC 按阶段分配候选实验，按各设备分别记录耗时。没有同配置串行对照时，不填并行加速倍数。模板没有实验结果，所有指标在实际执行后填写。
