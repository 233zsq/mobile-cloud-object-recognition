# v0.1.0 发布准备

本页保留首个体验包的准备与验证记录。PR #11 已合入 main，远端已有 `v0.1` 标签；后续网页修复记录见 [2026-10-12 网页更新](../web-responsive-20261012.md)。本轮不移动既有标签，后续发布应固定到包含修复的新提交。

## 本版内容

- Android 拍照／相册识别，支持手动选择本地或云端；默认离线，失败可重试或手动转本地。
- 识别记录、纠错、同步与模型筛选；网页展示云端记录及统计。
- 统一「观察手册」界面与扫描标签图标；设置拆为四个二级页，主页面删除顶部编号副标题。
- 两端使用 `campus-evolve-v2`，固定 10 类，模型及标签哈希保持一致。

## 安装与使用

体验包文件名为 `campus-recognition-v0.1.0-preview-debug.apk`，应用内部版本为 `0.1.0`。这是调试签名包，供组内体验与演示，不作为正式发布签名基准。安装包不包含组内访问口令；新设备由组内管理员另行提供，在「我的 → 云端连接」填写。默认本地识别无需云端连接。

发布附件应包含 APK、`SHA256SUMS.txt` 和验证记录。照片、训练检查点、私有审批、环境、访问令牌和签名私钥不上传；APK 内只有模型和已注明来源／许可的交接样例。

## 已验证与尚待完成

- 最新简化页头的构建成功；4 项模拟器界面检查通过，覆盖识别模式、历史模型筛选、二级设置返回和未保存输入保留。
- 既有验证记录：105 项 JVM 单元检查，20 张参考图片及传输副本的真实 HTTPS 端云对照；最近的网页标识更新有 11 项隔离数据审核回归通过。各项原始验证对应其记录中的提交，不能当作本次重新运行全部检查。
