# 双端界面基调

用户确认采用浅色背景、深青绿主色和紧凑布局。Android 与 Web 沿用同一组颜色、信息层级和状态语义；现有功能逐页整理，不改变识别与同步流程。

## 颜色

| 用途 | 颜色 | 使用方式 |
| --- | --- | --- |
| 主色 | `#16705C` | 主按钮、选中项、焦点与主要图表 |
| 页面背景 | `#F3F6F2` | 整页底色 |
| 内容表面 | `#FFFFFF` | 表单、列表和内容区域 |
| 主要文字 | `#17302E` | 标题、正文和重要数字 |
| 次要文字 | `#667A77` | 时间、模型版本和辅助说明 |
| 分隔线 | `#DFE8E4` | 轻边框和分区，不用于正文 |
| 选中／已同步底色 | `#DDEFE7` | 配深色文字，始终附状态名称 |
| 普通状态底色 | `#EDF3EE` | 待同步等中性状态，避免整块高饱和颜色 |
| 错误／危险操作 | `#B03A2E` | 错误提示、删除操作，同时说明原因或范围 |

## 排版与控件

- 用系统中文字体。每页一个主标题；主要数字突出，时间、版本和说明降低视觉权重，保留清晰可读的字号。
- 间距以 4 为基数，常用 8、12、16、24；页面两侧保留 16～24 的间距。内容区圆角 12～16，输入与按钮圆角 8。
- 使用细边框、低阴影和留白。连续记录使用紧凑的白色列表行；同一组筛选和计数放在同一区域，减少重复卡片。
- 一个区域突出一个主操作。删除等低频危险操作放入更多菜单，执行前确认实际影响范围。
- 选择器有可见标签；模型筛选称“模型版本”，默认“全部模型”，条目显示真实版本号。筛选记录不代表切换推理模型。
- Android 触控目标至少 48dp，Web 至少 44px。支持窄屏、字体放大和键盘焦点；长版本号允许截断，选择列表保留可辨别的版本信息。
- 默认固定浅色，Android 关闭壁纸动态取色。拍照预览保留相机画面，周围控件与结果区沿用同一主题。

## 记录与统计

- 筛选条件同时作用于记录和对应计数；显示当前范围，不能把修正比例写成模型准确率。
- 每条记录显示产生该结果的模型版本，方便解释历史差异。模型选项从实际数据读取，避免写死 v1/v2。
- Android 记录是本机记录；Web 是已入库记录。未同步、只在云端保留或已从本机删除的记录会导致两侧数量不同，需要在界面中说明范围。
- “同步全部”“清空全部本地记录”始终作用于整个本机库；筛选后仍按全库数量提示，避免把可见记录数量当作删除范围。
- 无记录、当前筛选无结果、连接失败分别说明，并提供返回全部、重试等直接操作。

## 本次落地与后续

Android 基础主题见 `android/app/src/main/java/com/mobilecloud/recognition/ui/theme/Theme.kt`；记录页首批应用模型筛选、计数、轻边框与版本展示。

云端统计页已有上述主色和模型筛选，样式入口为 `web/assets/css/dashboard.css`。后续 Android 采集／设置、Web 统计与审核页面改版都以本规范为基准。此次不重复添加网页已有入口，也不引入在线下载或切换推理模型。
