# 双端界面基调：观察手册

用户确认采用 A「观察手册」：奶油白、深森林绿、少量亮黄绿，大标题与编号、相机取景框、票据式识别结果。Android 使用 Compose 自定义排版和选择控件，保留 CameraX、系统图片选择器、导航及无障碍语义。

视觉原型保存在独立分支 prototype/bold-campus-ui，提交 f07dce4。正式代码重新实现，不部署原型或示例数据。

## 色彩与排版

| 用途 | 颜色 | 使用方式 |
| --- | --- | --- |
| 主色／主要文字 | #183F32 | 识别按钮、选中模式、网页侧栏和正文 |
| 背景 | #F6F3E8 | 奶油白整页底色 |
| 票据／表面 | #FFFDF5 | 结果、输入框和列表 |
| 强调色 | #D7EF78 | FIELD NOTES 印记、当前导航项 |
| 辅助文字 | #58695D | 时间、版本与说明 |
| 细分隔线 | #D2D5C6 | 区域与票据边界 |
| 错误 | #B03A2E | 失败原因、危险操作，始终附文字 |

- 标题使用系统衬线字体回退，编号采用等宽字体；正文使用系统中文字体。无需下载字体。
- 页面边距约 20～24dp，间距以 4 为基数。相机与模式切换使用大圆角，结果票据使用小圆角，避免所有区域都成为重复卡片。
- Android 触控目标至少 48dp，Web 主操作至少 44px。选中项保留语义与文字，不能只靠颜色辨认。
- 固定浅色，关闭壁纸动态取色；支持竖屏滚动、窄屏和字体放大。网页筛选可展开，模型、来源等现有条件均保留。
- 原型中的插画、记录、数字均不进入正式界面；正式页展示相机画面和实际数据，未连接时显示空状态。

## 本地／云端识别

- 识别页默认本地，可手动选择本地或云端，拍照与相册共用入口。推理过程中锁定模式及新的拍照／导入操作。
- 本地识别无需网络；结果通过原有同步流程上报，照片保存在本机。
- 云端模式明确提示上传图片至组内服务。传输前生成直立 JPEG 副本，最长边不超过 2048、质量 92，清除 EXIF 及位置信息；导入原图最多 32 MiB，传输副本最多 8 MiB。缩小和重新编码可能改变输入，因此对照验证必须使用同一份传输副本。
- 云端使用现有设置中的地址与令牌；响应的请求编号、模型版本、完整 SHA-256、类别顺序、Softmax 向量、置信度和耗时通过检查后才写入本机记录。
- 云端失败保留照片，提供重试与手动转本地；不静默切换计算位置，不把失败请求写成识别记录。同步失败不否定已经保存的识别结果。
- 票据显示真实识别来源及计算耗时；云端另显示本次总等待，含图片准备、上传、网络和解码。统计上报的耗时仍为预处理与推理，不含网络等待。
- 这只选择计算位置，不下载或切换模型版本；两端继续使用 campus-evolve-v2。

## 记录与统计

- Room 升级到版本 2，显式迁移并为全部旧记录补上 device 来源，保留原预测、人工修正及同步状态。
- 每条记录显示产生该结果的模型和计算位置。模型筛选来自真实历史，列表和计数范围一致。
- Android 是本机记录；Web 是已入库记录。未同步、只在云端保留或已从本机删除的记录会导致数量不同。
- 同步全部、清空全部本地记录仍作用于全库，删除前按全库数量说明范围。
- 人工修正比例不能作为模型准确率。独立实拍和真机性能验收仍单独记录。

## 验证与部署

- 单元检查覆盖端云响应身份、分数与耗时校验，以及来源上报。
- 模拟器检查覆盖真实模式选择、历史筛选、旧库迁移、传输副本方向与元数据清除、真实 multipart 请求和认证失败。
- 获得指定模拟器凭据写入授权后，再执行真实 HTTPS 同图验证；凭据保存在应用私有设置，APK 和 Git 不包含令牌。
- 网页样式部署只覆盖 index.html 和 dashboard.css，先备份原文件，核对文件哈希及 API 健康；不变更 443 配置、推理模型或 8443 审核服务。
