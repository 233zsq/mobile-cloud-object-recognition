# 范围提示基础版：scope-basic-v1

2026-10-13，试验版本，用于安卓本地及 `/ios/` 网页云端的 campus-evolve-v2。没有重训模型、增加类别或调用付费模型。

## 使用行为

本地模型仍返回十类完整分数和原始 Top-1。最高分至少 55%，并且前两名分数差至少 20 个百分点时，通过基础确认规则。其余结果提示「暂不确定」，可能是角度、遮挡、类别混淆，也可能是范围外物品；提示不是已经确认的未知类别。

- 实时观察：不确定时显示候选和原因，不会因重复猜同一类而成为稳定结果。普通结果仍需连续三帧一致。
- 拍照和相册：不确定时保留当前照片并显示本机缩略图，暂停实时分析，暂不生成记录。用户可确认候选、选择实际类别并保存，或不保存并重拍。
- 人工选择其他类别时，原预测、置信度和模型版本保留，通过原有修正字段记录实际类别和修订号。
- 通过规则的普通照片沿用原保存流程。安卓云端 v1/v2 仍使用原有低置信提示；网页在验证云端响应后应用同一基础规则。
- 网页未通过时保留当前照片预览，暂停新识别及模型切换，暂不保存到本机记录或上报。可确认候选、选择实际类别并保存，或不保存并重拍。确认另一类别后仍上报原预测，再通过原纠错接口提交修正。
- 规则仅与 v2 的完整身份匹配。网页选择旧 v1、规则丢失、哈希或身份不符时仍可推理，但全部转人工确认，不借用 v2 的验证结论。网页旧记录不追溯修改。

待确认任务保存在当前页面会话中，应用重新启动后不会恢复这项任务。没有增加跨进程草稿管理或未知类别记录接口。用户选择不保存时会删除当前私有照片副本。

网页待确认任务同样只保留在当前打开的页面，刷新或关闭会丢弃。确认保存后的网页记录额外保留完整分数、规则状态、适用规则哈希和人工确认标记；这些字段只供本机展示及备份，不改变云端记录接口。

## 身份与失败处理

正式模型包及其状态保持不变。独立规则文件位于 `shared/policies/scope-basic-v1/`，与 `android/app/src/main/assets/scope/` 字节一致。规则 SHA-256：

`3011b2f0b71a0592d17e598693af6f57b8155a05350afc43d521dc6df98bd842`

加载时检查规则摘要、完整模型和标签摘要、类别版本、预处理版本。任一不匹配即停用规则，保留原始模型预测并要求人工确认；实时结果会明确提示规则不可用。没有把规则写进原模型 metadata，也没有改变十类接口或 Room 数据结构。

网页规则嵌入 `web/ios/model-contract.json`，按原 CRLF、两空格缩进还原字节后校验相同摘要。`.gitattributes` 禁止 Git 转换共享及安卓规则文件的换行，避免检出后身份变化。

## 已做的开发实验

使用冻结的 `campus-evolve-data-v2` 全部 609 张公开验证照片，独立 LiteRT CPU 环境运行现有 FP32 模型。仅比较事先列出的少量门槛组合，以已知物品自动确认覆盖率至少 90%作为可用性约束。最终使用 55%/20个百分点。

| 指标 | 数量/结果 |
|---|---:|
| 已知验证照片 | 609 |
| 自动确认 | 584，95.89% |
| 转人工确认 | 25，4.11% |
| 原始准确率，全部照片为分母 | 91.46% |
| 自动确认部分准确率 | 93.15% |
| 正确且自动确认，占全部已知照片 | 89.33% |
| 专门审核的范围外评估照片 | 0 |
| 范围外拒绝率 | 未测量 |

93.15%只对应被放行的子集，不能写成模型准确率提升。25张需要确认的照片中也有原来预测正确的样本。验证集参与了规则选择，结果不是独立测试成绩；范围外物品可能仍被模型高置信误认并放行。

已复现一个用户提供的开发反例：墙上的壁虎被当前 v2 预测为钥匙，分数约 99.9914%，基础规则自动通过。这证明规则无法处理所有高置信范围外误判。该照片仅用于失败诊断，未加入训练或正式测试；单个开发反例不构成范围外评估集。

报告及各类计数：`experiments/reports/scope/scope-basic-v1-validation.json`。完整分数仅保存在本地交付目录。没有读取受保护测试图片；原模型和阈值冻结后的正式测试不能用来调整这套新规则。

## 复现

在已有独立 CPU 环境中，将 `PYTHONPATH` 指向本仓库的 `ml/src`。照片在另一个本地数据目录时，通过 `RECOGNITION_ROOT` 指向保存完整冻结数据的目录。

```text
python scripts/probe-scope-policy.py --release <完整v2模型目录> --data-version campus-evolve-data-v2 --output <新的输出目录>
```

入口固定只读取验证集；输出目录已存在则拒绝覆盖。脚本保存模型和清单摘要、完整分数、各候选统计及规则文件。Python和安卓均按float32计算门槛。

下一步应准备人工确认的范围外开发与留出照片，并补手机已知物品开发照片，再评价误放行率和误拦截率。正式评估时同时冻结模型哈希、规则哈希与预处理版本；换规则后不能反复利用旧独立测试选门槛。

网页核心回归：`node --test web/ios/tests/core.test.cjs`。
浏览器流程回归需要 Playwright 和可用 Chromium：`node --test web/ios/tests/scope.browser.cjs`；已有 Edge 的 Windows 可设置 `PLAYWRIGHT_CHANNEL=msedge`。全部接口在本机模拟，不生成真实云端测试记录。
