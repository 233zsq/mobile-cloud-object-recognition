# 安卓界面与云端模型选择

安卓保留一个本地模型 `campus-evolve-v2`，默认本地识别。选择“云端识别”后，在取景区上方选择模型；拍照和相册共用该选择，推理期间锁定选择。失败保留照片，可重试或手动改用本地。

界面延续奶油白、森林绿、亮黄绿的观察手册风格：紧凑页头、大标题、双层模式按钮、明确的拍照操作、票据结果和浮动底部导航。识别完成后滚动到票据；设置仍为四个二级入口，记录保留模型筛选。

## 模型清单与请求

`GET /api/models` 使用现有Bearer认证，返回 `default_model_version` 与 `models`。每项包含：

- `model_version`、`model_sha256`、`labels_sha256`、`category_version`、`labels`。
- `low_confidence_threshold`、`status=frozen`、`available`。
- `display_name` 与 `description`。

不返回服务器文件路径。当前提供推荐的 `campus-evolve-v2` 和保留的 `campus-gpu-v1`；后者采用早期类别口径，仅作对比。不同版本的类别键与输出顺序相同，类别版本和阈值分别以冻结元数据为准。

`POST /api/infer` 原有字段不变：image、request_id、model_version。服务器只路由已登记的明确版本，未知版本返回409，不替用户选择默认模型。推理不写正式记录，客户端校验成功后通过既有记录接口上报实际使用的模型版本。

Android和识别网页均先验证清单、标签哈希与阈值；每次请求前复查所选模型。规格改变、服务不可用、响应哈希错误或分数不符时保留照片并报错。已选择v1不要求与本地v2的分数一致；同版本端云对照仍使用相同输入张量及传输副本。

## 服务运行与回退

独立CPU进程预加载两个已批准的模型，分别核验发布包及完整哈希，每个预热20次。两个模型共享一个图像解码／推理准入名额，超过时立即返回繁忙，避免同时解码和叠加推理占用。进程沿用现有512MiB上限。

`INFERENCE_REGISTRY` 指向运维拥有的绝对路径JSON清单；空值兼容原单模型部署。CPU进程通过 `--registry` 读取同一清单，每个Unix socket请求携带明确版本，健康检查也核对对应版本。`/api/health`继续表示默认v2的状态，不代表用户刚才选择的模型。

部署脚本 `deploy/scripts/deploy_cloud_models.py` 只接收固定提交、校验过的公开源码包及两个现有批准模型包。比较依赖锁，运行隔离检查，追加核对类别和模型登记，保留原口令、TLS、端口和数据库结构。激活失败恢复原源码指针、配置和进程；回退材料保存在后端 `shared/model-rollbacks/*-multi-model/`。

网页静态包随后用已有原子发布入口单独更新。未通过就绪检查前，原网页和APK仍能用默认v2。

## 验收范围

检查应覆盖模型隔离路由、未知版本拒绝、跨模型共享并发上限、哈希／标签／阈值校验、离线本地仍可用、选择锁定、历史实际版本及升级保留原数据。真实推理只用已有公开交接样例，避免为功能测试写入正式记录。

模拟器截图和模型切换正确不代表真机准确率或P95性能验收；独立实拍测试继续单独进行。

## 2026-10-12 已完成的验证与部署

安卓109项单元检查、6项MuMu检查通过，包含两个模型的真实HTTPS推理及各自的完整哈希核对；功能验证不新增正式识别记录。后端15项接口、6项真实Unix socket、7项部署检查和16项网页核心检查通过。

以1080×2400、density 420的标准长屏为主要视觉检查，同时验证MuMu的1080×1920、density 480矮屏；取景区随可用高度改变，首屏直接显示拍照操作。长屏AVD的API37预览与当前Espresso输入接口不兼容，仪器化检查改在MuMu通过，长屏保留实际显示截图验证。

服务已激活两种模型，默认仍为v2；CPU进程观测峰值约162MiB，低于原512MiB限制，此数值不作为性能或负载验收。识别网页同时部署模型选择入口，手机及PC布局无横向溢出、控制台无错误。

测试APK使用现有调试签名，版本名仍为0.1.0；未更改签名密钥。包内只包含一个本地v2，已核对模型二进制哈希。原MuMu保留数据升级，未向新AVD写入口令；新AVD只检查本地界面。

完整回执、源码版本、模型与APK哈希见 [android-cloud-models.json](../experiments/reports/deployment/campus-evolve-v2/android-cloud-models.json)。
