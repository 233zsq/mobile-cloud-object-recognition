# 笔袋商品图补充

2026-10-11按用户提供的必应“笔袋”图片搜索结果，保存57张候选商品照片，原始下载量13,806,202字节（约13.2MiB）。来源包括1688商品页及其他商品展示页；不是Commons/Open Images数据，也不是自采照片。完整来源与文件哈希保存在 `data/manifests/product-pencil-20261011.csv`。

57个文件SHA-256均不同，感知哈希距离≤6的候选对为0；与480行历史及当前预留测试身份没有冲突。该检查不保证同一款商品被不同卖家拍摄时都能被识别；审核时仍需合并已识别的同款拍摄系列。每个商品页初始共用一个重复组。无效的多链接拼接结果不下载。

候选统一使用 `web_product` 来源，作者未知时留空，许可标记为 `unverified (product photo; permission not established)`。**商品图可用性审核不等于获得训练或再分发许可**；训练清单与模型材料须保留该状态，使用前确认相应授权。不把商品图计为自采成果。

照片单独导入审核网站，继续使用Flash初审、Max复核疑难及约5%抽检的现有策略；单批≤50张、累计费用及调用上限不重置。新照片不写入已冻结的 `campus-evolve-data-v2`，也不自动开始训练或发布模型。需要框选、标签不确定或错误的图片继续交人工处理。

## 复现采集

先从浏览器实际可见的搜索结果选择来源，保存UTF-8 TSV，每行两列：原始图片HTTPS地址、商品页HTTPS地址。采集器只接受已观察到的图片主机，不抓取整站、不下载搜索缩略图代替原图。

```powershell
python scripts/collect-product-candidates.py --root <本地数据目录> --sources <来源.tsv> --output <本轮目录> --max-new 60
python review/deploy/prepare_public.py --root <本地数据目录> --manifest <本轮目录>/candidates.csv --output <审核包.zip>
```

默认最多60张（显式上限120），单文件≤5MiB，单轮成功响应正文≤128MiB，仍共用全部公开来源的单类750张及总原图3GiB上限。原图完整保留，检查静态JPEG/PNG/WebP、尺寸、解码、SHA-256及测试集身份；候选清单默认待审核。中途保存清单，再次处理同一来源列表时复用已下载记录。

审核网站回归测试144项、采集和数据导入测试39项通过。原有TensorFlow集成测试此次未完成，不将其计作已通过；本次未修改训练计算或执行模型训练。
