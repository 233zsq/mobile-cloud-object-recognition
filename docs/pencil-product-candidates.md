## 复现采集

先从浏览器实际可见的搜索结果选择来源，保存UTF-8 TSV，每行两列：原始图片HTTPS地址、商品页HTTPS地址。采集器只接受已观察到的图片主机，不抓取整站、不下载搜索缩略图代替原图。

```powershell
python scripts/collect-product-candidates.py --root <本地数据目录> --sources <来源.tsv> --output <本轮目录> --max-new 60
python review/deploy/prepare_public.py --root <本地数据目录> --manifest <本轮目录>/candidates.csv --output <审核包.zip>
```

默认最多60张（显式上限120），单文件≤5MiB，单轮成功响应正文≤128MiB，仍共用全部公开来源的单类750张及总原图3GiB上限。原图完整保留，检查静态JPEG/PNG/WebP、尺寸、解码、SHA-256及测试集身份；候选清单默认待审核。中途保存清单，再次处理同一来源列表时复用已下载记录。

审核网站回归测试144项、采集和数据导入测试39项通过。原有TensorFlow集成测试此次未完成，不将其计作已通过；本次未修改训练计算或执行模型训练。
