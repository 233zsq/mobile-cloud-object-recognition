# 文档与课程交付

| 文件或目录 | 内容 |
| --- | --- |
| `planning/README.md` | 本地规划资料的位置与归档规则 |
| `planning/project-development-plan.docx` | 已有开发计划书的本地副本，不随公开仓库同步 |
| `planning/task-allocation.md` | 已有完整分工的本地副本，不随公开仓库同步 |
| `architecture.md` | 模块边界与主要数据流 |
| `api/README.md` | 从计划书整理的接口草案，后续由前后端冻结 |
| `model-contract.md` | 类别、预处理、标签顺序与模型交接要求 |
| `environment.md` | 待填写的工具、依赖和设备版本清单 |
| `report/` | 实践报告与配图 |
| `presentation/` | 答辩 PPT 与讲稿 |
| `demo/` | 演示步骤、版本清单与录屏存储位置 |

规划资料中的指标与日期属于计划；运行、性能和验收结论必须由实际证据支持。修改材料时核对代码、模型、数据、APK 和服务版本。
