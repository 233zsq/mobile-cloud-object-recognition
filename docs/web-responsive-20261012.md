## 已修复

- 清理超过300条的记录时，从最旧的已同步记录开始，保护待同步项和冲突项。
- 上传、纠错、联网与定时重试共用顺序队列；旧纠错响应只确认发送的修订，不覆盖发送期间的新修改。
- 409冲突保留本机修改，支持采用云端修正或以新修订提交；404重新上传原记录。
- 本机存储失败明确提示并提供导出入口；保持原存储键，升级保留既有数据。
- 固定并核对模型版本、SHA-256、标签、10类分数及阈值，异常响应不写入记录。
- 443使用现有可信IP证书与自动续期，正常访问无需手动信任证书。静态资源只发布7个运行文件，采用原子切换并保留前一版本。

后端、模型、数据库及审核站没有随本轮更新切换。Android已有系统证书信任配置，本轮未修改应用功能或重新生成APK。
