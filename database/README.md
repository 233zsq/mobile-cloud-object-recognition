# 数据库结构与初始化

负责人：数据与云端负责人。首版使用 MySQL，当前没有可执行 SQL。

- `schema/`：版本化建表和升级 SQL。
- `seeds/`：正式类别和必要的初始化数据；类别从冻结的共享清单生成。

按开发计划书建立 `category`、`model_version`、`inference_record`、`sample` 核心表。识别记录的 `record_id` 为稳定 UUID；原预测与人工标签分别保存，纠错依靠递增修订号防止旧请求覆盖新标签。类别与模型字段保持引用一致性。

数据库只保存必要的元数据、路径和哈希，照片文件另行管理。结构实现后在本文件记录执行顺序、数据库版本和迁移方式，在 `deploy/README.md` 记录备份、恢复与验证步骤；数据库备份不提交到 Git。
