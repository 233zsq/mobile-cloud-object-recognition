# 腾讯云部署

负责人：数据与云端负责人。计划使用已有2核4GB Linux服务器部署Flask、Gunicorn、MySQL、Nginx、Web静态页面，以及LiteRT Python运行时加载的同版FP32 tflite CPU模型。

当前预留 `nginx/` 和 `systemd/` 目录，没有生效的服务配置或已部署服务。后续填写：

1. 服务器系统、Python/Flask/LiteRT/Gunicorn/MySQL/Nginx版本与磁盘余量。
2. Flask源码与依赖、静态文件、tflite模型/标签和元数据的版本、哈希及路径。
3. 数据库初始化、真实配置注入、访问认证、HTTPS 与反向代理配置。
4. systemd 自动重启、日志查看和健康检查方式。
5. 数据库、样本清单与必要照片的备份、恢复命令及实测结果。
6. 手机端API地址、单图片推理调用、模型状态检查、回退与演示前检查。
7. 初始一个worker和受控推理并发下的CPU、内存、耗时及失败率；推理与记录查询并行时的影响。

模型启动时加载并校验，初始一个Gunicorn worker，按实测调整线程、推理并发和连接池。Nginx提供HTTPS及反向代理，systemd管理服务重启；正式部署不使用Flask开发服务器。

真实令牌、数据库密码、私钥与备份仅保存在受控环境。云端承担CPU推理、记录和统计，训练在本地PC完成，上传照片默认处理后释放。实际启动、发布和回退命令在实现后补充，当前不能直接部署。
