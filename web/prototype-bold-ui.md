# 双端视觉探索

这是 `prototype/bold-campus-ui` 分支上的一次性原型，用于比较安卓识别页和云端统计页的三个方向，不接入正式页面或服务。

在仓库根目录运行：

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory web
```

打开 <http://127.0.0.1:8765/prototype-bold-ui.html?variant=A>。底部按钮或键盘左右方向键切换方案；也可将 URL 的 `variant` 设为 `B` 或 `C`。

- A：观察手册，奶油白、森林绿与识别票据。
- B：扫描实验室，深色相机界面与仪器式控制台。
- C：物品索引，大字、硬边与不对称排版。

可以尝试本地／云端切换、模拟拍照、安卓底部导航、安卓和网页的模型筛选。全部记录和推理结果都是示例数据，不调用相机、不上传照片、不保存业务数据；刷新后交互状态重置，视觉方向保留在 URL 中。

正式 App 当前仅接入本地识别，云端入口属于待确认的实现范围。选定方向后应在正式分支重新实现，并验证相机、无障碍、失败恢复及本地／云端的数据来源记录。Compose 可绘制自定义界面，无需改用其他框架。

验证记录：三个方向均已在浏览器渲染；切换云端预览后显示云端计算和总等待示例，筛选 `campus-gpu-v1` 后示例记录从 48 条变为 16 条。原型仅供本机访问，脚本没有外部资源或网络请求。
