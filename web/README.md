# Web 统计页

负责人：数据与云端负责人。首版采用 HTML、CSS 与 JavaScript。

当前预留 `assets/css/`、`assets/js/`、`assets/images/`。开发时在本目录增加 `index.html` 与静态资源，不要求引入前端构建框架。

基础页面展示类别分布、数量趋势、耗时、低置信数量和最近识别记录，每 5 秒请求后端统计及记录接口，并显示刷新时间和失败状态。原预测与人工纠正的统计口径分别标明；日常纠错比例不能充当独立模型准确率。

API 草案见 `docs/api/README.md`。部署时优先采用同域反向代理。不要将长期服务端凭据写入公开 JavaScript 文件，认证交互由前后端共同确定。页面完成后补充本地访问与部署方式。
